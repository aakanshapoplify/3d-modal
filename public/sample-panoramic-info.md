# Sample Panoramic Images

To test the panoramic view feature, you can use any panoramic image. Here are some suggestions:

## Free Panoramic Images
- Download from Unsplash: https://unsplash.com/s/photos/panoramic
- Pixabay: https://pixabay.com/images/search/panoramic/
- Pexels: https://www.pexels.com/search/panoramic/

## Image Requirements
- **Format**: JPG, PNG, WebP
- **Aspect Ratio**: For best results, use 2:1 aspect ratio (equirectangular)
- **Resolution**: Higher resolution images provide better viewing experience

## Testing the Feature
1. Go to the "Panoramic View" tab
2. Select "PhotoSphereViewer" mode
3. Upload a panoramic image
4. Use the interactive viewer to navigate around the image

The viewer supports:
- **Drag**: Pan around the image
- **Mouse Wheel**: Zoom in/out
- **Zoom Controls**: Use the + and - buttons in the bottom right

## Creating Panoramic Images
If you want to create your own panoramic images:
1. Take multiple photos while rotating your camera
2. Use photo stitching software like:
   - Adobe Photoshop (Photomerge)
   - Microsoft ICE (Image Composite Editor)
   - Hugin (free, open source)
   - PTGui (professional)

## Tips
- For best results, use images with 2:1 aspect ratio
- Ensure the image is a true 360° panorama
- Higher resolution images provide smoother navigation
